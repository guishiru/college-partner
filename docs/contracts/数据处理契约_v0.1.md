# 数据处理契约 v0.1

## 目标

为统计引擎提供可追溯的分析数据视图，同时保留原始上传文件不变。

## 允许的自动处理

- 识别 CSV 编码和分隔符。
- 去除列名和单元格首尾空格。
- 将空字符串标记为缺失。
- 将全部非空内容都能明确解析为数字的文本列转换为数值，并记录转换。
- 将无穷值标记为问题。

## 禁止的静默处理

- 不跳过 CSV 坏行。
- 不把非法文本填成 0。
- 不自动把百分比、区间、等级文本猜成数值。
- 不自动填补缺失值。
- 不在重复列名时擅自决定列的业务含义。

## 输出

数据处理必须返回：

- 分析数据视图。
- 原始行数和列数。
- 处理后行数和列数。
- 列类型。
- 缺失数量。
- 非法值数量。
- 所有自动处理记录。
- 阻塞问题和警告。
- 是否可以进入统计引擎。
