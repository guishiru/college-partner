# 数据处理契约 v0.1

## 目标

为统计引擎提供可追溯的分析数据视图，同时保留原始上传文件不变。

## 允许的自动处理

- 识别 CSV 编码和分隔符。
- 去除列名和单元格首尾空格。
- 将空字符串标记为缺失。
- 将全部非空内容都能明确解析为数字的文本列转换为数值，并记录转换。
- 将无穷值标记为问题。

## 禁止的静默处理

- 不跳过 CSV 坏行。
- 不把非法文本填成 0。
- 不自动把百分比、区间、等级文本猜成数值。
- 不自动填补缺失值。
- 不在重复列名时擅自决定列的业务含义。

## 输出

数据处理必须返回：

- 分析数据视图。
- 原始行数和列数。
- 处理后行数和列数。
- 列类型。
- 缺失数量。
- 非法值数量。
- 所有自动处理记录。
- 阻塞问题和警告。
- 是否可以进入统计引擎。

## 必须提示但不代替用户决定

以下情况能读进来也能分析，但必须以警告形式明确告知，不得静默通过：

- 工作簿包含多张表：读取数据量最大的一张，并列出全部表名和各自行列数。
- 列中含千分位逗号或百分号：按分类变量处理，不自动转换（22% 是 22 还是 0.22 需要用户判断量纲）。
- 全空列：说明纳入分析会清零其他变量的样本量。
- 常数列：说明其方差为 0，无法参与需要变异的分析。

以下情况必须阻塞：

- 所有列名都是数字：首行很可能是数据而非表头，直接分析会丢失一条样本。
