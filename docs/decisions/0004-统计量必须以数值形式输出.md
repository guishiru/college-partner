# 0004 统计量必须以数值形式输出，文本只是它的派生物

## 状态

部分完成。已处理三处最严重的；其余登记在 `tests/test_structured_statistics.py` 的 `STRING_ENCODED_DEBT` 中。

## 背景

项目约定里有一条：报告模块不得自行计算统计量，只能引用已授权的分析结果。做报告模块之前检查了一遍，发现这条规则在当前实现下**根本无法遵守**——有些统计量在结果里压根不以数值形式存在。

扫描 11 个方法的全部输出，共 **37 处**统计量只以格式化字符串存在。最典型的三处：

| 位置 | 症状 |
|---|---|
| 相关分析 | 整个结果只有一张字符串矩阵，原始 r 和 p 在结果里不存在 |
| CFA 因子相关矩阵 | 同上，且 p 值被压成 `0.000***` |
| 线性回归模型级统计量 | R²、F、自由度、p 只在 `display` 的一句预渲染文本里 |

样本：

```
相关分析首行  {'X': '1.000', 'W': '-0.025(0.742)', 'M1': '0.566(<0.001***)'}
回归 display  模型汇总：R² = 0.376，调整R² = 0.366，F(3, 176) = 35.378，p = <0.001***
```

## 为什么解析不是出路

解析能拿回 `0.566`，但原值 `0.5659316361693452` 回不来了。更关键的是 `<0.001` 和
`0.000***`——**这不是数值，是一个界**。报告想写「p = 1.25e-16」，无论怎么解析都写不出来，只能退回去重算，而重算正是约定禁止的那条。

## 决定

**数值是事实，字符串是它的渲染。** 统计量一律以完整精度的数值列输出；展示用的格式化文本保留，但从数值派生，且在 `display` 的 notes 里写明「不要从中解析数值」。

已处理：

- 相关分析新增 `correlation_table`：每对变量一行，`相关系数` 与 `P值` 为完整精度数值列。原展示矩阵保留为派生物。
- CFA 新增 `factor_correlation_table` 与 `sqrt_ave_table`。原 `corr_table` 展示矩阵保留。
- 线性回归新增 `model_summary_table`：R²、调整 R²、F、模型自由度、残差自由度、P 值、样本数，全部为数值列。`model_summary_row` 文本改为由它派生。

现成的参照写法本来就在仓库里：调节分析的 `summary_table` 早就把 R² 和调整 R² 存成 `float64`。

## 尚未处理

另外 30 余处登记在 `STRING_ENCODED_DEBT`，分两类：

**丢精度（较急）**——值已被四舍五入或压成 `0.0***`，解析也拿不回真值：

- 平行中介的全部 p 值列（四个模型表加两张汇总表）
- 调节分析 `summary_table` 的 F 与 P
- EFA `total_variance_display_table` 的旋转后特征根与解释率
- SEM `measurement_table` 的 z 与标准误、`fit_table` 的卡方、自由度和全部拟合指标

SEM 那条影响最大：RMSEA、CFI、GFI 这些是 SEM 报告里必写的指标，现在全是字符串。

**仅类型（不急）**——字符串里是完整精度，只是同列混了 `-` 占位导致整列变成文本：

- CFA `load_table`、`cov_table` 的标准误 / Z / P
- 线性回归 `regression_table` 的 Beta 与 VIF（常数项显示为 `-`）

后者的根治办法是：表里存数值，不适用处存 `NaN`，由 `display` 配置规定「NaN 渲染为 -」。这是一次横跨全部方法文件的统一改造，单独作为一次变更做，不掺进这次。

## 防回归

`tests/test_structured_statistics.py`：

- 已改好的方法，关键统计量必须能以数值取到，取不到就报错；
- 相关分析、CFA、回归的最小 p 值必须小于 1e-6，被截断到展示精度就报错；
- 回归的展示文本必须与背后的数值一致，防止文本自己跑偏；
- 欠账清单只许变少不许变多：新出现的字符串统计量直接报错，已改好却还留在清单里也报错。

把欠账做成一份会报错的清单，而不是散落在各方法文件里靠人记得。

## 基线核对

黄金基线按表的 key 逐一比对（不能按位置，新增表会让索引整体移位）：三个方法共新增 4 张表，**既有统计数值零变化，零字段消失**。唯一的差异是 `meta.table_keys` 的顺序和一句注释文本。
